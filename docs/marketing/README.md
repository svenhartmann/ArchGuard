# Marketing kit / Marketingpaket

Stand / Updated: 2026-11-20. Local editorial material; nothing in this directory publishes or schedules a post.

## Deutsch

Das Paket setzt die Kommunikationsarbeit des Website-Marketingplans in verwendbare Texte und Arbeitsabläufe um. Die Wochen zählen ab der tatsächlichen Veröffentlichung der überarbeiteten Website, nicht ab dem Datum dieser Datei. Technische Fallstudien mit noch fehlenden Messungen bleiben Entwürfe.

| Material | Verwendung |
| --- | --- |
| [Kalender](calendar.md) | Themen, Verantwortungsrolle, Beleg und Abschlusskriterium für zwölf Wochen |
| [Launch DE](launch-de.md) / [Launch EN](launch-en.md) | Blog-Einstieg, Community-Post und Social-Text |
| [Fallstudien DE](stories-de.md) / [Fallstudien EN](stories-en.md) | Redigierbare Texte, Kommandos und konkrete Capture-Aufträge |
| [Verbreitung](distribution.md) | MCP-Eintrag, Awesome-Listen, Konferenz- und Demo-Brief |
| [Release-Vorlage](release-template.md) | Feature-Story mit echtem Clip und reproduzierbarem Beispiel |
| [Lehrübung](teaching.md) | 60-Minuten-Übung mit Bewertungskriterien und Lösungshinweisen |
| [Messung](measurement.md) | GitHub-Kennzahlen erfassen und sinnvoll interpretieren |

Veröffentlichungsreif auf der Website sind der [Werkzeugvergleich](../../site/compare/index.html) und der [Evidenz-Essay](../../site/stories/evidence/index.html), jeweils mit deutscher Fassung. Der Essay verwendet ausschließlich bestehende, ausgewiesene Aufnahmen.

Vor jedem externen Beitrag: Links auf die veröffentlichte Fassung setzen, installierte Version mit dem beschriebenen Feature abgleichen und die Regeln des gewählten Kanals lesen. Messwerte nur mit Commit, Analyseversion und Scope nennen. Keine fremden Projektlogos als Empfehlung verwenden. Ein unbekannter Wert bleibt unbekannt.

## English

This kit turns the website marketing plan into usable copy and workflows. Week one begins when the revised website actually ships. Case studies awaiting empirical evidence remain drafts.

The table above links the calendar, bilingual launch copy and case studies, directory and conference brief, release template, teaching exercise and measurement guide. The public [comparison](../../site/compare/index.html) and [evidence essay](../../site/stories/evidence/index.html) also have German counterparts.

Before external publication, replace preview links with the deployed URLs, check the described feature against the installed version and read the chosen channel's current rules. Every numerical claim needs a source revision, analysis version and scope. Upstream projects do not endorse ArchGuard. Unknown stays unknown.
