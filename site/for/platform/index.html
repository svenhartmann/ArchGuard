Analysis scope and prerequisites

ArchGuard reads supported source and configuration patterns, not live cluster state. It never runs Terraform or reads its state and variable files. Secrets remain unknown; Helm and Kustomize need explicit opt-in. Dynamic endpoints and unsupported resources remain gaps. A configured datastore does not prove runtime use.
