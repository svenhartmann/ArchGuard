EXAMPLES & EVIDENCE

About these examples

Real viewer captures, with their scope kept visible.

The screenshots on this site were captured from ArchGuard's local browser viewer on 4 November 2026, the flow video on 3 November 2026, both at 1440 × 960 pixels. They show Apache Commons Collections 4.6.0 and Microsoft eShop at revision 913acea66708a59595351174cee9b29f37179d29; the Service Shop example page keeps its capture from 31 October 2026. No graph or measurement was painted into the screenshots.

What the screenshots show

  • World View, Graph, Matrix, Calls and Quality: Apache Commons Collections with the repository's example configuration and production-source scope. The World View metric images use the Explore lens with Complexity, CBO, WMC and LCOM4; the package image opens org/apache/commons/collections4/map. Class metrics are partial where compiler-backed analysis did not cover a class.
  • Service map and source evidence: Microsoft eShop with the aspire:src/eShop.AppHost/AppHost.cs deployment and inferred event flow. The Catalog / Ordering / Payment Processor cycle is inferred from source and shared RabbitMQ configuration; it is not an observed runtime trace.
  • Services on the Service Shop page: Service Shop with API configuration selected. The two highlighted groups are configured HTTP cycles.

Screenshots show analysis at a point in time. Counts depend on the source revision, filters, graph granularity and available analysis tools. They are not a promise of complete runtime coverage.

Evidence and limitations

ArchGuard separates source dependencies, deployment configuration, declared architecture and imported runtime evidence. Missing references, dynamic dispatch and generated code can leave analysis gaps. Coverage and runtime metrics require imported measurements; unavailable values are not treated as zero.
