Was ohne zusätzliche Werkzeuge funktioniert

Die ausführbare ArchGuard-Datei liest Quell- und Konfigurationsdateien direkt. Importgraphen aller unterstützten Sprachen, Zyklen, Matrix, World View, Regeln und statische Service-Erkennung benötigen keine weiteren Werkzeuge. ArchGuard lädt dein Projekt nicht herunter, baut es nicht und stellt keine Pakete wieder her. Fehlt ein Werkzeug oder eine Projektvoraussetzung, wird die betroffene Analyse als nicht verfügbar oder teilweise ausgewiesen, statt den Lauf fehlschlagen zu lassen.

Sprachen

Die Analyse kombiniert compilerbasierte Adapter und Syntax-Scanner. Die Tabelle nennt Werkzeug und Grenzen jeder Sprache; ein installierter Compiler garantiert keine vollständige Abdeckung.

@@LANGUAGE_TABLE@@ 
# Java: export the classpath once, e.g. with Maven
mvn -q dependency:build-classpath -Dmdep.outputFile=.archguard/java-classpath.txt

# C#: restore packages so obj/project.assets.json exists
dotnet restore

# TypeScript: install the project compiler, then allow ArchGuard to run it
npm install
ARCHGUARD_TRUST_PROJECT_COMPILER=1 archguard calls . --format json

Der Maven-Befehl ist eine Möglichkeit, die Classpath-Zeile zu erzeugen; bei Gradle schreibst du den aufgelösten Runtime-Classpath in dieselbe Datei. archguard calls . --format json zeigt den Status pro Sprache und verbleibende Lücken.

Frameworks und Services

Die Service-Erkennung liest Quellen und Konfiguration, ohne Container zu starten oder einen Cluster zu kontaktieren. Das Rendern von Helm und Kustomize muss ausdrücklich aktiviert werden und startet dein installiertes Rendering-Werkzeug; siehe unten.

Importierte Berichte

ArchGuard liest diese Berichte; das erzeugende Werkzeug wird nie ausgeführt. Erzeuge die Berichte mit deinem üblichen Test- oder Analyseaufbau und importiere sie anschließend.

BelegAkzeptiertes FormatBefehl
TestabdeckungJaCoCo XML, Cobertura XML, Clover XML, LCOVarchguard coverage
Statische AnalysebefundeSARIF 2.1.0 (bis 32 MiB)archguard quality
TestergebnisseJUnit XMLarchguard test-evidence
Mutationstestsmutation-testing-elements JSON (zum Beispiel aus Stryker)archguard mutations
Duplizierter CodePMD CPD XMLarchguard duplicates

--help führt die Optionen jedes Befehls auf. Sprachen und Messgrenzen erklärt, wie importierte Messungen eingeordnet werden.

Deine Umgebung prüfen

archguard doctor
archguard calls /path/to/project --format json

archguard doctor meldet, ob git, java, dotnet und node gefunden werden, und gibt ihre Versionen aus. Mindestversionen, Go und Trivy werden nicht geprüft; der Exit-Status ist immer null. Der calls-Bericht zeigt, was jede Sprachanalyse für dein Projekt tatsächlich erreicht hat, einschließlich Teilergebnissen und ihrer Gründe.
