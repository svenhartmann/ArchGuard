ARCHGUARD HANDBUCH

Deine erste Analyse

Verfolge eine Abhängigkeit von der Übersicht bis zum Quellbeleg und prüfe das Projekt anschließend über die CLI.

Mit Service Shop starten

Installiere ArchGuard über die Installationsanleitung. Für diese Übung brauchst du einen Checkout des ArchGuard-Repositories und dessen Ordner examples/service-shop. Das Beispiel enthält einen bewusst gekoppelten Shop über mehrere Compose-Stacks. Für die Konfigurationsanalyse müssen keine Container laufen.

archguard doctor
archguard services examples/service-shop --format json

Desktop öffnen und einen Zyklus verfolgen

  1. Wähle Datei → Projekt öffnen… und den Ordner examples/service-shop.
  2. Öffne Services. Betrachte zunächst konfigurierte HTTP-Beziehungen; Startabhängigkeiten sind eine eigene Evidenzart.
  3. Verfolge catalog → pricing → promotions → catalog. Wähle eine Verbindung und lies ihre Quelldatei und Konfigurationsbelege.
  4. Untersuche orders → payments → risk → orders als zweite Zyklusgruppe. Eine Gruppe beschreibt gegenseitige Erreichbarkeit; sie beweist keine endlos laufende Anfrage.

Ergebnis im Terminal vergleichen

Führe den Architekturcheck aus und lies den Zyklusbericht. Befunde hängen vom gewählten Graphen und den Regeln ab: Service-Zyklen und ein Gate für Quellmodule beantworten unterschiedliche Fragen.

archguard check examples/service-shop
archguard cycles examples/service-shop --format json

Exitcode 1 beim Check bedeutet, dass Befunde das Gate verletzen. Lies zuerst den Befund und die Analyseabdeckung. Ein Werkzeugfehler oder eine ungültige Konfiguration benötigt eine andere Diagnose.

Auf dein Projekt übertragen

  1. Öffne die Repository-Wurzel oder für eine gezielte Untersuchung einen einzelnen Service.
  2. Prüfe mit archguard doctor die benötigten Sprachwerkzeuge.
  3. Erzeuge mit archguard init /pfad/zum/projekt eine erste Konfiguration und prüfe Quellverzeichnisse und Gates.
  4. Halte für einen Befund Quellstelle, Evidenzart und Umfang fest. Vergleiche nach einer Änderung denselben Umfang.

Bei leeren Graphen, unbekannten Metriken oder fehlenden Verbindungen hilft Probleme lösen. Danach kannst du die Desktop-Ansichten kennenlernen oder ein CI-Gate einführen.
