MCP und Coding-Agents

Verbinde die Analyse mit einem Agenten und stelle Fragen in natürlicher Sprache.

Einen stdio-Server verbinden

Installiere ArchGuard so, dass dein Agent-Client es ausführen kann. Registriere einen stdio-MCP-Server mit einem absoluten Projektpfad. Die folgende Konfigurationsstruktur ist üblich; der genaue Speicherort der Einstellungen hängt von deinem Client ab:

{
  "mcpServers": {
    "archguard": {
      "command": "archguard",
      "args": ["mcp", "--root", "/absolute/path/to/project"]
    }
  }
}

Wenn der Client den PATH deiner Shell nicht übernimmt, ersetze archguard durch den absoluten Pfad zur ausführbaren Datei. Der Server ist ein lokaler Prozess, kein separat gehosteter HTTP-Endpunkt. Starte oder verbinde ihn nach Änderungen an der ausführbaren Datei oder Client-Konfiguration neu.

Den Agenten fragen

ZielAnfrage in natürlicher Sprache
Ein Repository verstehen„Zeige die Anwendungen, Bibliotheken und Services in diesem Repository. Halte deklarierte Abhängigkeiten von beobachteten Laufzeitbelegen getrennt.“
Einen Zyklus erklären„Finde einen kleinen Abhängigkeitszyklus, zeige für jede Kante die Quellstellen und erkläre, warum ein Zyklus entsteht.“
eShop untersuchen„Zeige die Ereigniszyklusgruppe mit Ordering API. Identifiziere Publisher, Subscriber und Belege für den gemeinsamen Broker. Benenne, was abgeleitet ist.“
Komplexität untersuchen„Finde die komplexesten gemessenen Methoden im Checkout-Service. Nenne die Dateipositionen und erläutere fehlende Compiler-Belege.“
Eine Änderung prüfen„Vergleiche diese Änderung mit main. Erkläre neue Architektur-Findings und den Vergleichsumfang, bevor du Korrekturen vorschlägst.“
Ein Refactoring erproben„Simuliere das Entfernen dieser Abhängigkeit und vergleiche die Zyklusgruppen. Ändere keine Quelldateien.“
Dokumentation verbessern„Fasse die verfügbaren Bausteinbelege für arc42 zusammen und liste Entscheidungen auf, die noch eine menschliche Erklärung benötigen.“

Eine nützliche Antwort enthält Belege

Frage nach Projektumfang, Quellrevision, Beziehungsart, Dateipositionen und Abdeckungslücken. Bei seitenweisen Ergebnissen sollte der Agent den zurückgegebenen Cursorwerten nach Bedarf folgen oder angeben, dass er nur eine Teilmenge zeigt. Eine gekürzte erste Antwort ist nicht der vollständige Abhängigkeitsgraph.

Fordere bei Service-Fragen ausdrücklich die Unterscheidung zwischen Konfiguration, aus Quellen abgeleiteten Routen und beobachteten Traces. Verlange bei Metriken, dass unbekannte oder veraltete Werte als unbekannt oder veraltet erhalten bleiben.

Abfragen, Simulationen und speichernde Aktionen

Eine Graphsimulation verändert eine hypothetische Sicht, nicht die Projektquellen. Das Aufzeichnen von Review-Entscheidungen, Importieren von Berichten oder Schreiben von Dokumentation kann projektlokale Artefakte speichern. Sage, ob du eine Erklärung, eine Vorschau oder eine tatsächliche Aktualisierung möchtest, damit der Agent die passende Operation wählt.

Verbindungsprobleme eingrenzen

  • Prüfe die ausführbare Datei mit archguard --version in derselben Umgebung, die der Client verwendet.
  • Prüfe den absoluten Stammpfad und den Dateisystemzugriff.
  • Stelle sicher, dass der Client archguard mcp --root … als stdio-Server startet.
  • Unterscheide anhand der Client-Logs einen Startfehler von einem durch ein Werkzeug gemeldeten Analysefehler.
  • Starte den MCP-Prozess nach einem lokalen CLI-Neubau neu; ein bereits laufender Prozess verwendet weiterhin die Datei, mit der er gestartet wurde.
