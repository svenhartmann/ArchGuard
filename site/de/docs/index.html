Wo soll ich beginnen?

Neu bei ArchGuard? Installiere die CLI und öffne das enthaltene Demo unter Erste Schritte.

Ein unerwartetes Ergebnis untersuchen? Lies Sprachen und Messgrenzen und Fehlerdiagnose, bevor du Gates änderst.

Einführung im Team? Beginne mit ausdrücklichem Umfang und Regeln und ergänze dann ein geprüftes CI-Gate.

Mit einem Agenten arbeiten? Nutze Einrichtung und natürlichsprachliche Beispiele unter MCP und Coding-Agents.

Erster Lauf

archguard check /pfad/zum/projekt
archguard services /pfad/zum/projekt --format json
archguard mcp --root /pfad/zum/projekt

Öffne unter macOS ~/Applications/ArchGuard.app; unter Linux und Windows archguard-desktop. Zum Bauen aus dem Repository: cargo install --path crates/archguard-cli --locked. Der Installationsleitfaden enthält Release-Installation und PowerShell-Befehle.
