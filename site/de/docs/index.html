Dokumentation

Installiere ArchGuard, wähle deinen Analyseumfang und folge den Belegen bis zur Quelle. Desktop-App und arc42 unterstützen Deutsch und Englisch.

Erster Lauf

archguard check /pfad/zum/projekt
archguard services /pfad/zum/projekt --format json
archguard mcp --root /pfad/zum/projekt

Öffne unter macOS ~/Applications/ArchGuard.app; unter Linux und Windows archguard-desktop. Zum Bauen aus dem Repository: cargo install --path crates/archguard-cli --locked. Der Installationsleitfaden (EN) enthält Release-Installation und PowerShell-Befehle.

Workflows und Evidenz

Deployment, CI, MCP, Simulation, Exporte, Importe und SBOM.
