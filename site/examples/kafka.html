LARGE JAVA CODEBASE

Apache Kafka

Kafka 4.1.0 with 3,369 production Java files across 27 source roots. Analysis neither builds Kafka nor runs its code. This example uses revision 13f70256db3c994c590e5d262a7cc50b9e973204.

1. Get the example

Run from the ArchGuard repository root. The example configuration selects the production sources and excludes tests, test utilities, examples, benchmarks and other languages.

git clone --depth 1 --single-branch --branch 4.1.0 https://github.com/apache/kafka.git examples/checkouts/kafka
mkdir -p examples/checkouts/kafka/.archguard
cp -n examples/kafka.toml examples/checkouts/kafka/.archguard/archguard.toml

Open the folder in the ArchGuard desktop app with File → Open project…. On Linux and Windows you can also pass it on the command line: archguard-desktop examples/checkouts/kafka.

Class measurements require JDK 17+.

2. Recorded scope

Analysis on 10 November 2026 with ArchGuard 0.3.1 and the configuration above:

  • 3,369 production Java files and 16,321 directed dependencies.
  • 16,164 import references, each checked against its source line.
  • 48 cyclic groups at file level; the largest contains 175 files. An independent algorithm confirmed both numbers.
  • 5,222 landscape entries, of which 5,154 are classes or types and 4,479 have measured method complexity.

A group contains one or more possible cycles; the group count does not count every individual cycle.

3. Explore the landscape

On the Start tab, choose Architecture and step into org, apache and kafka. The Problems lens draws package cycles in red.

Rotate the landscape with Q/E or the rotation buttons. Moving the camera does not change analysis values.

A small direct file cycle in the unmodified sources: CommonClientConfigs.java:24 imports ClientTelemetryReporter, and ClientTelemetryReporter.java:19 imports CommonClientConfigs.

archguard cycles examples/checkouts/kafka --level file --format json
archguard hotspots examples/checkouts/kafka --top 20 --format json

Evidence boundary: Java analysis is partial. Build dependencies and generated types are missing, and not all Gradle expressions are evaluated. This run projects 2,333 inheritance references but no resolved calls. The strict example rule reports existing cycles; it does not represent Kafka's own architecture policy. The clone is shallow, which limits Git history metrics.
