Deployment and datastore boundaries

Read Compose, Kubernetes manifests and supported literal Terraform resources without containers, a cluster or state files. Helm and Kustomize rendering starts installed tools only after explicit opt-in. Missing modules, variables and table names remain analysis gaps.

archguard services . --format json
ARCHGUARD_RENDER_MANIFESTS=1 archguard services . --format json

Shared server means a common endpoint; shared database also requires the same database name. Shared table adds a matching table declaration from EF Core, JPA, TypeORM, SQLAlchemy or SQL migrations. None proves runtime access.

Review a change in CI

Start with explicit architecture rules. Save a baseline only after reviewing the current cycles; then check with that baseline. Compare against an existing Git ref to produce a review comment with KPI deltas.

archguard baseline write .
archguard check . --baseline
archguard review . --base main --format pr-comment

baseline writes a project artifact. A failing check is an expected result when rules are violated. The included GitHub Action supports Linux/macOS, SARIF and a sticky PR comment; fork PRs may have no permission to post.

Ask for bounded change context

Register the command as a stdio server in your agent client. Ask for change_context with exact source paths, then follow source references and unresolved selectors before proposing edits. Discover tools from tools/list instead of relying on a hard-coded tool count.

archguard mcp --root /path/to/project

Example request: “Which callers and policies are affected by this file?” This is a prompt suggestion, not a recorded conversation. Query budgets and analysis gaps remain part of the answer. Persistent operations such as baseline or report import require a deliberate request.

Simulate a refactoring

Export operations.json using Export SimOps in the viewer, or use --cut FROM,TO, --move NODE:PARENT and --merge SURVIVOR,ABSORBED with exact module names from the current graph.

archguard simulate . --ops operations.json --format json

The operations file must exist; the simulation reports a hypothetical graph delta without editing sources. Real refactoring still needs implementation, a fresh analysis and behavioural tests.

Export architecture documentation

Preview arc42 before writing, check generated evidence for drift and export selected documentation formats. Existing manual decisions remain important. The diagram catalogue shows which diagrams are included.

archguard doc . --arc42 --stdout
archguard doc . --arc42 --check
archguard doc . --arc42 --format docx
archguard doc . --arc42 --format asciidoc
archguard graph . --format structurizr
archguard review . --format markdown
archguard diagram .

docx and asciidoc write exports; graph writes a report under .archguard/reports. Word keeps diagram source rather than rendered images. Confluence import is a separate user action. Missing or outdated documentation makes --check fail.

Use the evidence you actually have

Import coverage, SARIF, JUnit, CPD and mutation reports from their producers. The built-in duplicate scanner is an alternative to importing CPD. Git history supports hotspots and co-change; CODEOWNERS supports ownership.

archguard hotspots .
archguard co-change .
archguard ownership .
archguard duplicates --help
archguard evaluate .

An ISO 25010 goal links to available evidence, not an automatic quality certificate. Recall and precision need an expert assessment. A shallow clone can miss churn and co-change history.

Contracts and observed runtime

Import OpenAPI for an exact service or read GraphQL schemas and supported tagged templates. A GraphQL baseline records schema state for later breaking-change comparisons. Runtime diagnostics require imported usable OTLP traces or probe output.

archguard contracts . --graphql-baseline
archguard runtime . --format json

The baseline command writes project data. Federation directives and nested selection validation are limited. N+1 or chatty-call candidates, slow statements and sampling profiles describe the captured workload only; static service maps are not traces.

Offline inventory, explicit licence policy

Export a CycloneDX 1.6 inventory from supported lockfiles and manifests without querying registries. Licences come only from input files that state them; missing licence information stays unknown.

archguard sbom . --format cyclonedx
archguard check .

An explicit allow/deny/unknown policy can gate the inventory. Advisory scanning is separate and uses Trivy. Do not infer a dependency licence from the licence of its parent project.
