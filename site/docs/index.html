How to use the handbook

Search for tasks, concepts or exact commands. Results link directly to the relevant section. Open screenshots in the overlay to inspect details. Configuration examples belong in .archguard/archguard.toml unless stated otherwise.

Replace example names such as Admin, Order and service IDs with values from your project. Feature coverage records the documented source snapshot and load-simulation availability.
