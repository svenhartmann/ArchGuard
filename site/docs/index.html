Where should I start?

New to ArchGuard? Install the CLI and open the included demo in Getting started.

Investigating an unexpected result? Read Languages & measurements and Troubleshooting before changing gates.

Rolling out to a team? Start with explicit scope and rules, then add a reviewed CI gate.

Working through an agent? Use the setup and natural-language examples in MCP & coding agents.
