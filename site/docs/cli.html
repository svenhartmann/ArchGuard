The everyday commands

archguard serve .
archguard check .
archguard cycles . --format json
archguard calls . --format json
archguard services . --format json

Most workflows start with one of these. The broader CLI also supports imports, evidence review and automation; you do not need to run every command for a normal project exploration.

Find exact arguments

archguard --help
archguard serve --help
archguard workspace --help
archguard baseline write --help

--config selects a configuration file. --quiet suppresses summary and finding output on stdout. --verbose requests extra diagnostics. A global format appearing in help does not mean every command accepts it: for example, Mermaid is specific to cycles and SARIF to check. Graph exports have their own format selection.

Source and repository scope

archguard scan . --level file --out /tmp/archguard-graph.json
archguard workspace . --sources --format json
archguard graph . --format html

scan extracts a source graph; workspace --sources adds isolated project source analysis to a workspace model. HTML export is a report, whereas serve runs the live local viewer. Output and cache artifacts can be written under .archguard/; these commands are not all filesystem-free queries.

Generate architecture documentation

archguard doc . --arc42 --stdout
archguard doc . --arc42
archguard doc . --arc42 --chapter 5 --check

Preview with --stdout, write with the second form, and use --check to detect drift without writing. Chapter selection accepts 1 through 12. Generated evidence blocks do not replace human architecture decisions.

Simulate before changing code

archguard simulate . --cut "application,domain"

The names above are placeholders: replace them with actual nodes in the current module view. Simulation changes the hypothetical graph, not source files. Verify an implemented change with a fresh analysis and the project's own tests.

Know which actions persist data

Configuration initialization, baseline writing, report imports, review recording, documentation generation, security scans and snapshots can write project-local artifacts. Commands with explicit read-only modes document those modes in help. The MCP server offers access to the same evidence-oriented workflows; do not assume every operation is a read-only query.
