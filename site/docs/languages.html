Installation details, environment variables and what your project must provide are listed per language in Tools & prerequisites.

Compiler-backed analysis needs the project's references to understand its symbols. A tool being installed does not guarantee full coverage. Missing dependencies, generated sources and dynamic constructs can leave a partial result.

archguard doctor
archguard calls /path/to/project --format json

Doctor reports external-tool availability; its exit status is always zero. It is diagnostic output, not a CI coverage gate. The Calls report supplies the actual analysis status and gaps.

Reading source metrics

Class and method metrics depend on a compatible producer. Complexity, CBO, RFC, WMC and cohesion measurements answer different questions; use KPI help in the viewer's settings menu for their definitions and scope. Do not compare a method's complexity directly with a package aggregate.

Go embedding is composition rather than class inheritance. DIT and NOC are not applicable to Go. Missing source measurements should remain unknown, not be replaced with a visually convenient zero.

Measurements from other tools

Coverage, test outcomes, mutations, dependency advisories, duplication and runtime measurements are separate evidence inputs. ArchGuard does not invent those results from imports. Generate a report with the appropriate producer, then use the matching import command.

archguard coverage . --report coverage.xml --source-root .
archguard quality . --report findings.sarif --source-root .

The first example requires a supported coverage report and source-path mapping. The second imports SARIF findings. Check each command's help and the viewer's KPI help for accepted formats and producer-specific setup. A report for another source revision can be stale even when it parses successfully.

Compare like with like

  • Keep the project root, source exclusions and aggregation level consistent.
  • Record the source revision and available compiler tools.
  • Distinguish distinct relationships from counts of evidence references.
  • Read partial, stale, unmapped and unknown states before interpreting a trend.
