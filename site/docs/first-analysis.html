ARCHGUARD HANDBOOK

Your first analysis

Follow one dependency from an overview to its evidence, then run the same check in the CLI.

Start with Service Shop

Install ArchGuard using the installation guide. For this walkthrough, use an ArchGuard repository checkout and its included examples/service-shop directory. It contains a deliberately coupled shop across Compose stacks. You do not need to start the containers to inspect configuration.

archguard doctor
archguard services examples/service-shop --format json

Open the desktop and find a cycle

  1. Choose File → Open project… and select examples/service-shop.
  2. Open Services. Start with the configured HTTP relationships, keeping startup dependencies separate.
  3. Follow catalog → pricing → promotions → catalog. Select a connection and read its source file and configuration evidence.
  4. Inspect orders → payments → risk → orders as a second cycle group. A group describes mutual reachability; it is not proof that a request loops forever.

Compare the terminal result

Run the architecture check and inspect the cycle report. Findings depend on the selected graph and rules; a service-cycle view and a source-module gate answer different questions.

archguard check examples/service-shop
archguard cycles examples/service-shop --format json

Exit code 1 from a check means findings crossed the gate. Read the finding and analysis coverage before changing thresholds. A failed tool or invalid configuration needs separate diagnosis.

Repeat on your project

  1. Open the repository root, or one service for a narrower investigation.
  2. Run archguard doctor and install the tools required by its languages.
  3. Use archguard init /path/to/project to create initial configuration, then review its source roots and gates.
  4. Record one finding with its source location, evidence type and scope. Compare the same scope after a change.

For an empty graph, unknown metrics or missing service connections, follow Troubleshooting. Next, learn the desktop views or introduce a CI gate.
