MCP & coding agents

Connect the analysis to an agent and ask questions in natural language.

Connect a stdio server

Install ArchGuard where your agent client can execute it. Register a stdio MCP server with an absolute project path. The following configuration shape is common, but the exact settings location depends on your client:

{
  "mcpServers": {
    "archguard": {
      "command": "archguard",
      "args": ["mcp", "--root", "/absolute/path/to/project"]
    }
  }
}

If the client does not inherit your shell's PATH, replace archguard with the executable's absolute path. The server is a local process, not a separately hosted HTTP endpoint. Restart or reconnect it after changing the executable or client configuration.

Ask the agent

GoalNatural-language request
Understand a repository“Show the applications, libraries and services in this repository. Keep declared dependencies separate from observed runtime evidence.”
Explain a cycle“Find a small dependency cycle, show the source locations for each edge, and explain why it forms a cycle.”
Inspect eShop“Show the event-cycle group containing Ordering API. Identify the publishers, subscribers and shared broker evidence. State what is inferred.”
Investigate complexity“Find the most complex measured methods in the checkout service. Include file locations and explain any missing compiler evidence.”
Review a change“Compare this change with main. Explain new architecture findings and the scope of the comparison before suggesting fixes.”
Try a refactoring“Simulate removing this dependency and compare the cycle groups. Do not edit source files.”
Improve documentation“Summarize the available building-block evidence for arc42 and list the decisions that still need a human explanation.”

A useful response includes evidence

Ask for project scope, source revision, relationship kind, file locations and coverage gaps. When results are paginated, the agent should follow returned cursors as needed or state that it is showing a subset. A truncated first response is not the complete dependency graph.

For service questions, explicitly request the distinction between configuration, inferred source routes and observed traces. For metrics, request unknown or stale values to remain unknown or stale.

Queries, simulations and persistent actions

A graph simulation changes a hypothetical view, not the project source. Recording review decisions, importing reports or writing documentation can persist project-local artifacts. State whether you want an explanation, a preview, or an actual update so the agent can choose the appropriate operation.

Connection troubleshooting

  • Verify the executable with archguard --version in the same environment the client uses.
  • Check the absolute root path and filesystem access.
  • Ensure the client starts archguard mcp --root … as a stdio server.
  • Use client logs to distinguish a startup failure from an analysis error returned by a tool.
  • Restart the MCP process after a local CLI rebuild; an already-running process continues using the executable it started with.
