ARCHGUARD HANDBOOK

Quality and supply chain

Combine source metrics, external reports, an offline inventory and explicit advisory scans.

Import evidence from an actual tool run

Create the reports with your test or analysis tools first. Paths below are examples; --source-root is only needed when it helps map report paths to your project.

archguard metrics . --extended
archguard coverage . --report coverage.xml --source-root src
archguard quality . --report findings.sarif --source-root src
archguard test-evidence . --report junit.xml
archguard mutations . --report mutation-report.json --source-root src
archguard duplicates . --report cpd.xml --source-root src

Coverage accepts JaCoCo, Cobertura, Clover or LCOV; quality findings use SARIF 2.1.0; tests use JUnit XML; mutations use mutation-testing-elements JSON; duplicate reports use CPD XML. The report-import commands read saved evidence when --report is omitted; they do not execute its producer. metrics --extended computes current source metrics.

Scan duplicates and check changed code

archguard duplicates . --scan --min-tokens 100
archguard quality . --base main --min-changed-coverage 80 --max-complexity 15 --max-nesting 4

The built-in duplicate scan performs analysis explicitly. It will not replace imported CPD without --replace. Changed-code thresholds are policy examples; import suitable coverage before using them. Unknown measurements do not become zero. Static test-impact recommendations do not prove other tests safe to skip.

Create an offline dependency inventory

archguard sbom . --format cyclonedx > sbom.cdx.json
archguard sbom . --format json

The CycloneDX 1.6 inventory uses local manifests and lockfiles. It does not query registries or an advisory database. Unknown versions and licences remain unknown; first-party workspace/path references are excluded.

[licenses]
allow = ["MIT", "Apache-2.0", "BSD-3-Clause"]
deny = ["GPL-3.0-only"]
unknown = "allow"

This example policy belongs in .archguard/archguard.toml. archguard check . enforces it; SBOM export itself does not fail the policy. Choose explicitly how unknown licences should behave. Exact SPDX IDs matter.

Run or read an advisory scan

archguard security .
archguard security . --cached
archguard security . --offline
archguard security . --cached --fail-on-found

The first command invokes installed Trivy and saves results. Cached mode only reads saved evidence. Offline mode still invokes Trivy using an existing local database; it cannot be combined with cached mode. --fail-on-found exits 1 for advisories and 3 for missing, stale or incomplete evidence.

Review coverage before accepting a result

Record the source revision, producer, scan time, mapped paths and omitted scope. A partial scan with zero findings cannot establish that every dependency is free of vulnerabilities. Keep report provenance when sharing results or comparing revisions.

Use CI gates for policy enforcement and languages and metrics for measurement availability. MCP exposes the corresponding quality, coverage, test-impact, mutation, duplication, SBOM and security evidence.
